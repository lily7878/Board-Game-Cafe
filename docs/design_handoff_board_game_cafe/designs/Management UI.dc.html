Context and decisions
Built from Frontend Specification v1.0 and corrected Atlas Vizual. Shape language comes from the Organic design system (pill buttons/inputs/tags, 24–32px radii, soft warm shadows, round accents); its terracotta and Caprasimo are swapped for the spec palette and Manrope.

Atlas corrections applied
• Login has no role picker — role comes from the backend account.
• Table drawer has five tabs: Rezumat / Participanți / Comenzi / Jocuri / QR-PIN.
• No photos or covers — games and products use icons and text.
• Statuses are pastel colors, always with a label and an icon. Green is used only for success or free.
• Dashboard depends on role; Manager gets Administrare + Ziua curentă / EOD. No hourly charts.
• Topbar shows the simulated business day, live connection and notification bell.
